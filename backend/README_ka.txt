შეცდომის შემთხვევაში შეჩერდით და არ გააგრძელოთ მომდევნო ნაბიჯი. ახალი Python დამოკიდებულება არ არის. მიგრაცია ამატებს ხუთ ci_ ცხრილს, არსებულ api_users-სა და api_token_sessions-ს იყენებს. main.py-ს სკრიპტი აკეთებს ასლს და ამატებს როუტერს, საჭირო HTTP მეთოდებსა და მასწავლებლის სერვერულ შეზღუდვას. Apache-ის ცვლილება არ სჭირდება.

მასწავლებლები
სახელი, გვარი, ტელეფონი, ელფოსტა, შესვლის სახელი და მინიმუმ 12-სიმბოლოიანი პაროლი. ახალი მასწავლებლისთვის იქმნება ცალკე api_users ანგარიში. პაროლი ინახება არსებული scrypt ჰეშით და უკან არ ბრუნდება. რედაქტირებისას ცარიელი პაროლი ნიშნავს უცვლელს. შესვლის სახელის/პაროლის შეცვლა აუქმებს მასწავლებლის მიმდინარე სესიებს. წაშლა დამალავს მასწავლებელს და გათიშავს მის ანგარიშს; უსაფრთხო წვდომის კავშირი ინახება, რომ გათიშული ანგარიში ადმინისტრატორად არ იქცეს. მომხმარებლის სახელი კვლავ დაკავებული რჩება.
მასწავლებელი ხედავს მხოლოდ საკუთარ კალენდარს. სხვა API-ების წვდომა სერვერზეც იბლოკება, მხოლოდ მენიუს დამალვა არ არის. არსებული ჩვეულებრივი ანგარიშები თავიანთ მონაცემებს მართავენ.

ჯგუფები
დასახელება, სტუდენტების რაოდენობა, ატვირთული პროგრამის ერთ-ერთი სასწავლო გეგმა. ჯგუფის ქვეშ აირჩიეთ მოდული და მასწავლებელი. მოდულების სია მოდის მხოლოდ ამ ჯგუფის გეგმისგან. ერთ მასწავლებელს შეიძლება უკავშირდებოდეს რამდენიმე მოდული და რამდენიმე ჯგუფი. ერთსა და იმავე კავშირს ორჯერ ვერ დაამატებთ. სხვა მომხმარებლის გეგმა/მასწავლებელი/ჯგუფი ვერ მიებმება.
კავშირის შეცვლა: ჯერ ამოიღეთ ძველი კავშირი, შემდეგ დაამატეთ ახალი. დაკავშირებული გაკვეთილების არსებობისას კავშირის წაშლა შეჩერდება; ჯერ შეცვალეთ ან წაშალეთ ისინი. აქტიური კავშირების მქონე ჯგუფის გეგმის შეცვლაც შეზღუდულია.

აუდიტორიები
დასახელება/ნომერი, შენობა, ადგილების რაოდენობა და ტიპი — სასწავლო ოთახი, კომპიუტერული ოთახი, ლაბორატორია, სახელოსნო ან საკუთარი ტიპი. შენობისთვის ცალკე ცნობარი ჯერ არ არის — იწერება ტექსტით.

კალენდარი
ადმინისტრატორი „განრიგის კალენდარში“ ამატებს კონკრეტულ გაკვეთილს: ჯგუფი/მოდული/მასწავლებლის კავშირი, აუდიტორია, დაწყება და დასრულება. დრო არის თბილისის ადგილობრივი დრო, ერთ დღეში, წუთის სიზუსტით. მასწავლებელი იმავე გვერდზე მხოლოდ საკუთარ გაკვეთილებს ხედავს.
გადაფარვა აკრძალულია მასწავლებლისთვის, ჯგუფისთვის და ოთახისთვის. წინა გაკვეთილის დასრულების მომენტში მომდევნოს დაწყება დასაშვებია. აუდიტორიის ტევადობა მოწმდება; ჯგუფის რაოდენობის ან ოთახის ტევადობის შეცვლაც მოწმდება უკვე დაგეგმილ გაკვეთილებთან. მონაცემების შეცვლასა და შეჯახების შემოწმებას მფლობელის DB ჩაკეტვა იცავს.
ჯერ არ არის სრული სასწავლო გეგმიდან ავტომატური დღიური განრიგის გენერაცია ან გაკვეთილების ავტომატური გამეორება. დასვენებების/მოდულის საათების ავტომატური განრიგი ამ ხელით დამატებულ გაკვეთილებს ჯერ არ აკავშირებს. სხვა ანგარიშებს შორის საერთო მასწავლებლის/ოთახის ცნობარი არ არის.
დაკავშირებული მონაცემების წაშლა მოთხოვნისას შეჩერდება გასაგები შეტყობინებით; დაკავშირებული გაკვეთილები ჩუმად არ იშლება. უკვე დაკავშირებული გეგმის მოდულების შეცვლა შეიძლება FK კავშირების გამო შეჩერდეს.

იმპორტის შესწორება
იმპორტში აირჩიეთ „ავტომატურად — ფურცლის განლაგების მიხედვით“. თქვენი სამი ფაილიდან შემოწმდა ოთხი ფურცელი:
- ქსელი .bak(2), დასამტკიცებელი უთარიღოდ: 23 მოდული, 75 კვირა.
- ქსელი .bak(2), ძირითადი: 23 მოდული, 75 კვირა; დამოუკიდებელი საათების კვირეული განაწილება არ არის, ამიტომ ცარიელი მნიშვნელობები შენარჩუნებულია და გაფრთხილებები ჩანს.
- კომპ(1), ძირითადი: 23 მოდული, 80 კვირა.
- Front-end, სასწავლო გეგმა: 13 მოდული, 45 კვირა.
ავტომატურად იკითხება ერთ-, ორ- და სამსტრიქონიანი მოდულები, განყოფილებების სათაურები, კვირების სვეტები და ორ სტრიქონზე გაყოფილი ჯამები. Front-end-ის პირველ მოდულში 91+9 = 100, საკონტაქტო 86, შეფასება 5, დამოუკიდებელი 9. მეორე სტრიქონის საათები აღარ იკარგება.
Excel ფაილები არ შეცვლილა. ავტომატურ რეჟიმში წყაროს ცნობილი შეუსაბამობები გაფრთხილებადაა შენარჩუნებული და იმპორტი მათ გამო არ იბლოკება. ეს არ ნიშნავს, რომ წყაროს საათები შეცვლილია ან საბოლოო განრიგისთვის ვალიდურია. კვირეული დამოუკიდებელი თუ არ არსებობს, არ გამოიგონება და ნულად არ გადაიწერება. ინფორმაცია და გაფრთხილებები გადაამოწმეთ შენახვამდე. ხელით ა/ბ/ძველი რეჟიმები შენარჩუნებულია.

შემოწმება
API SQLite ადაპტერით: CRUD, კავშირების შესაბამისობა და იზოლაცია, დროის 3 სახის შეჯახება, ტევადობა, მეზობელი საათები, წაშლის დაცვა, ნამდვილი პაროლითა და ტოკენით მასწავლებლის შესვლა, მხოლოდ საკუთარი კალენდარი და ადმინისტრირების API-ების აკრძალვა. რეალური სამი Excel-ის ოთხივე მითითებული ფურცელი: preview/save/load. React: DOM სიმულაციით ფორმები, კავშირი, მასწავლებლის მენიუ და მხოლოდ წასაკითხი კალენდარი; production build. რეალურ MySQL-ზე კონკურენტული ჩაკეტვა და ბრაუზერში ვიზუალური ჩვენება ამ გარემოდან არ შემოწმებულა. სერვერზე არ ატვირთულა.
