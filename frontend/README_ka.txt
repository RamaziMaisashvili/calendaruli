პროგრამის იმპორტი — React

შენარჩუნებულია ავტორიზაცია ტოკენით, 15-წუთიანი დროები, რესპონსიული მენიუ
და კომპიუტერის ხედში მენიუს ჩაკეცვა/დამახსოვრება.
შეიცვალა მხოლოდ პროგრამის იმპორტისა და სასწავლო პროგრამების გვერდები;
სხვა განყოფილებები ისევ ცარიელი გვერდებია.

განახლება
ჯერ განაახლეთ API და შემოიტანეთ API პაკეტის program_import.sql.
არსებული frontend ჩამოტვირთეთ სარეზერვო ასლად.
ამ ZIP-ის dist საქაღალდის შიგთავსი ატვირთეთ SFTP-ით
/calendar.learn.net.ge/ საქაღალდეში. თავად dist საქაღალდე არ ატვირთოთ.
Ctrl+F5-ით განაახლეთ გვერდი და მენიუში აირჩიეთ „პროგრამის იმპორტი“.

ადგილობრივი მუშაობა Windows-ის პროექტის ტერმინალში
npm ci
npm run dev

ასაწყობად
npm run build
API მისამართი არის https://api.learn.net.ge და იცვლება .env-ში VITE_API_URL-ით.
ბაზის პაროლი ან სერვერის ფაილები frontend-ში არ ჩაიწეროს.

იმპორტის ეტაპები
1. .xlsx ან .xlsm ფაილის არჩევა და წაკითხვა.
2. პროგრამის სახელი, სასწავლო წელი, დაწყების თარიღი და პროგრამის ტიპი;
   ფურცლის, სტრიქონების, სვეტებისა და კვირების პარამეტრების არჩევა.
3. მოდულების, კოდების, კატეგორიებისა და საერთო საათების შესწორება;
   ზედმეტი მოდულის ამოღება შესაძლებელია წინასწარი სიიდან.
4. კვირის არჩევა და თითოეული მოდულის კვირის საათების შესწორება.
5. შეჯამება და დადასტურების შემდეგ შენახვა.
ამ ეტაპამდე მონაცემები ბაზაში არ იწერება. უკან გადასვლა ველებს ინარჩუნებს.
სხვა მენიუზე გადასვლა ან გვერდის განახლება დაუშენახავ მონახაზს დაკარგავს.
სასწავლო პროგრამების გვერდზე გამოჩნდება მხოლოდ თქვენი შენახული გეგმები.
განრიგის შექმნა და იმპორტირებული გეგმის შემდგომი რედაქტირება ამ რელიზში არ არის.

შემოწმება
Vite production build წარმატებულია.
DOM სიმულაციაში API-ის საცდელი პასუხებით გაიარა:
ფაილის არჩევა, multipart ატვირთვა, პარამეტრები, მოდულების ნახვა,
კვირის საათის შესწორება, მხოლოდ დადასტურებით შენახვა, შედეგის ჩვენება,
პროგრამების სია და მენიუს ჩაკეცვა.
რეალური ბრაუზერის ვიზუალური და რეალურ სერვერთან ერთობლივი ტესტი აქ არ შესრულებულა.
